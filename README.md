# استودیوی تصویر — بهنود امیری

ابزار مستقل تغییر اندازه و تبدیل JPG، PNG و WebP؛ پردازش محلی در مرورگر، بدون آپلود، حساب کاربری یا پرداخت.

## اجرا
فایل index.html را در مرورگر جدید باز کنید. هر دو فایل index.html و studio.js باید کنار هم باشند. پشتیبانی خواندن AVIF/BMP و نوشتن WebP به مرورگر وابسته است. سقف ورودی ۲۰ مگابایت، ۲۴ مگاپیکسل و ضلع خروجی ۶۰۰۰ پیکسل است؛ روی موبایل ممکن است حافظه زودتر تمام شود.

## مالکیت و مشارکت
نگهدارنده اصلی: **بهنود امیری (Behnood Amiri)** — https://behnoodamiri.ir/
این نسخه از ابزار پروژه بهنود استخراج شده است. مجوز: **GPL-2.0-or-later**. استفاده تجاری نیز مجاز است؛ حقوق و اعلان‌های مؤلفان و مجوز را حفظ کنید. حقوق مشارکت‌کنندگان متعلق به خودشان می‌ماند؛ مشارکت به معنی انتقال مالکیت به نگهدارنده نیست. نام و نشان تجاری سایت، داده کاربران و خدمات پولی جزو مجوز این کد نیستند.

پیشنهادها را با Issue و Pull Request ارسال کنید؛ تغییرها فقط پس از بررسی نگهدارنده وارد نسخه اصلی می‌شوند. رمز، فایل واقعی کاربر، کلید درگاه یا اطلاعات پزشکی ارسال نکنید.

## دامنه نسخه
این مخزن سیستم حساب، پرداخت، پروفایل و خروجی‌های اختصاصی سایت را منتشر نمی‌کند. اجرای محلی ابزار به معنی دسترسی به خدمات سایت نیست. برای خدمات پشتیبانی، سفارشی‌سازی و آموزش با سایت نگهدارنده تماس بگیرید.
